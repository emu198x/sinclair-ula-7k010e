# sinclair-ula-7k010e

The Sinclair 7K010E, the ZX Spectrum 128K and +2's ULA.

| Crate | Registry |
|---|---|
| [`emu198x-sinclair-ula-7k010e`](crates/emu198x-sinclair-ula-7k010e) | [crates.io](https://crates.io/crates/emu198x-sinclair-ula-7k010e) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the 128K and +2.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
